## Notes

### Offensive Security (Red Teaming)
- Focuses on attacking systems to identify vulnerabilities  
- Simulates real-world cyberattacks to test defenses  

### Defensive Security (Blue Teaming)
- Involves responding to security incidents  
- Collects and analyzes data to prevent future attacks  

### Careers in Cybersecurity
- Security Analyst  
- Security Engineer  
- Incident Responder  
- Malware Analyst  
- Penetration Tester (Pentester)  
- Red Teamer
