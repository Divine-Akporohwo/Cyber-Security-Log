# Lesson 5: How Websites Work 💻  
Platform: TryHackMe 🧠  
  
---  
  
## Core Concept 🌐  
Websites are made up of:  
- Front-end (Client-side) 🖥️  
- Back-end (Server-side) ⚙️    
  
---  
  
## Web Technologies 🛠️  
  
HTML – Structure 🧱    
CSS – Design 🎨    
JavaScript – Interactivity ⚡    
  
---  
  
## HTML Basics 📄  
  
DOCTYPE HTML – Browser interpretation rule    
HTML – Root of page    
HEAD – Metadata    
BODY – Visible content    
  
Elements:  
H1 – Heading    
P – Paragraph    
IMG – Image    
BUTTON – Button    
  
---  
  
## Security Concepts 🔐  
  
Sensitive Data Exposure    
- Sensitive info found in source code    
  
HTML Injection    
- Unfiltered input injected into page    
  
---  
  
## Website Architecture 🧱  
  
Load Balancer – Distributes traffic ⚖️    
CDN – Speeds up content delivery 🌍    
Database – Stores data 🗄️    
WAF – Protects against attacks 🛡️    
Web Server – Handles requests 🌐    
Virtual Hosting – Multiple sites on one server 🏠    
Static Content – Fixed content 📌    
Dynamic Content – Changes based on input 🔄    
Backend – Application logic ⚙️    
  
---  
  
## THE COMPUTER 💻  
  
### Boot Sequence 🚀  
- Power button → PSU    
- UEFI/BIOS starts    
- POST checks hardware    
- Boot device selected    
- Bootloader starts OS    
  
---  
  
### Computer Types 🖥️📱  
Laptop    
Desktop    
Workstation    
Server    
Smartphone    
Tablet    
IoT devices 🌐    
Embedded systems 🔧    
  
---  
  
### Client-Server Model 🔗  
Client sends request → Server responds    
  
---  
  
### Virtualization 🧠  
One machine runs multiple virtual machines using a hypervisor    
  
Hypervisor Types:  
- Type 1 – Runs on hardware    
- Type 2 – Runs on OS    
  
---  
  
### Containers 📦  
Lightweight isolated environments running single apps
